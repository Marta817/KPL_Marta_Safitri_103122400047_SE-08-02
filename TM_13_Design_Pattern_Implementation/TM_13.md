## Soal
Jelaskan dengan kemampuanmu apa itu event delegation dalam design pattern JavaScript. Tidak ada batas bobot kata dalam menjawab tugas ini, tetapi penilaian akan bergantung dari sepaham apa dan sebagus apa kamu menyajikan jawabanmu.

## Deskripsi 
Event delegation dalam pattern desain JavaScript adalah metode di mana kita hanya membutuhkan satu event listener pada elemen induk (parent) untuk menangani event yang terjadi pada elemen-elemen anak (child). Pendekatan ini berfungsi karena adanya sistem event bubbling di DOM. Jadi, ketika kita mengklik atau memberikan aksi pada elemen anak, aksi tersebut akan mengalir ke atas hingga mencapai elemen induknya. Di elemen induk ini, kita hanya perlu menggunakan event.target untuk memastikan elemen anak mana yang sebenarnya sedang diinteraksi. Alih-alih memasang fungsi satu per satu pada masing-masing elemen anak yang dapat membuat memori browser terbebani jika jumlahnya mencapai ratusan kita cukup menerapkan satu fungsi saja di elemen induk. Selain membuat performa web menjadi lebih ringan, teknik ini juga sangat berguna ketika kita sering menambahkan elemen baru secara dinamis.
